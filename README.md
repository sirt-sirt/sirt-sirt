## 🧩 Projects

### 🔬 [oscar-nethunter-kernel](https://github.com/sirt-sirt/oscar-nethunter-kernel)

Custom Linux 5.4.280-qgki kernel for **Realme 9 Pro 5G** (`oscar`, Snapdragon 695) with
**Kali NetHunter** support. Full Kali chroot, USB OTG devices, strict clang **CFI + LTO
preserved**, and all 39 vendor modules rebuilt into a fresh `vendor_dlkm.img` —
so the phone stays a fully working phone.

> CI-gated builds, byte-for-byte vermagic checks, EROFS image verification. Flashed & validated on real hardware.

<br>

`Android` `Linux kernel` `Qualcomm SM6375` `CFI/LTO` `GitHub Actions` `EROFS`

### 🔧 [DFLU — Discord Fix Loop Update](https://github.com/sirt-sirt/DFLU-Discord-Fix-Loop-Update)

A surgical one-liner CLI fix for Discord's infamous **infinite update loop** and silent
startup crashes. Repairs the installation *without reinstalling* — keeps your login and
settings, purges cache and junk, relaunches Discord.

```powershell
irm https://raw.githubusercontent.com/sirt-sirt/DFLU-Discord-Fix-Loop-Update/main/run.ps1 | iex
```

<br>

`Windows` `Batch` `PowerShell` `CLI`
